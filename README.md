# SVARGA
<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/e7f2951a-cf16-4bab-8749-0ad9f826a69d" />

Для реализации дипломной работы использовался движок Unity 2023.1.16f1. Сама игра предсталяет собой небольшой рогалик с генерацией уровня. Результатом разработки стала альфа-версия проекта. <i>Альфа версия является сырым продуктом и содержит ошибки и недароботки.</i>

<h3>Про генерацию:</h3>
<p>В сцене уровень генерируется последовательно. По сути, в игре есть готовые префабы комнат, у которых на границе расположен RoomSpawner. Он определяет, какая комната будет заспавнена следующей.</p> 
Есть два типа последних комнат. Первый тип является выходом из сцены генерации, возвращая игрока в лобби. Второй тип перезапускает сцену, но с сохранением инвентаря.
Если игрок умрёт в сцене генерации, то это будет считаться за пройгрышь. В результате чего игрок потеряет часть инвентаря.
<h3>Про NPC:</h3>
Для реализации NPC использовался <a href="https://github.com/h8man/NavMeshPlus">NavMeshAgent</a>, адаптированный под 2D.
<h3>Про предметы:</h3>
В игре есть несколько типов предметов:
<ul>
<li>10 оружий. Некоторое оружие имеет дополнительные эффекты. Например, дополнительный урон и т.д.</li>
<li>10 заклинаний. Есть как и атакующие заклинания, так и заклинания восстанавливающие здоровье.</li>
<li>20 еды. Еда может быть полезной, так и отравленной.</li>
<li>Около 5 амулетов. Амулеты работают только в сцене генерации. При выходе из генерации все амулеты удаляются.</li>
<li>Душа. Особый предмет, который выпадает с врагов. Его надо тратить в алтаре.</li>
</ul>
<h3>Про графику</h3>
Для создания графики использовался конвейер URP 2D, Shader Graph и Visual Effect Graph. А также много изображенний, нарисованных в Aseprite.
<hr>
Для запуска собранного проекта скачайте папку "build.zip" и запустите SVARGA.exe.
